
## ClownFish 是什么

ClownFish 是一个“小而美”的.NET工具类库，包含开发单个应用程序的基础功能：
- [数据库访问](https://dev.fdcyun.com/3data/index.html)
- [HttpClient](https://dev.fdcyun.com/8client/http.html)
- [日志](https://dev.fdcyun.com/11logging/logging.html)
- [周期任务调度](https://dev.fdcyun.com/6task/introduce.html)
- [消息订阅管道](https://dev.fdcyun.com/5mq/pipeline.html)
- [常用工具类](https://dev.fdcyun.com/7utility/index.html)
- [对Asp.netcore的轻量封装](https://dev.fdcyun.com/10extension/alone2.html)
- [提供经典的HTTP管道开发模式](https://dev.fdcyun.com/10extension/http-pipeline.html)
