

ClownFish.Web 基于ClownFish.net，对asp.net core的封装，用于开发单体Web应用程序。
<br />与直接使用asp.net core相比：
- 包含了ClownFish.net所有功能(直接可用)：
    - [数据库访问](https://dev.fdcyun.com/3data/index.html)
    - [HttpClient](https://dev.fdcyun.com/8client/http.html)
    - [日志](https://dev.fdcyun.com/11logging/logging.html)
    - [周期任务调度](https://dev.fdcyun.com/6task/introduce.html)
    - [消息订阅管道](https://dev.fdcyun.com/5mq/pipeline.html)
    - [常用工具类](https://dev.fdcyun.com/7utility/index.html)
- MVC-Action的执行过程会自动生成[日志](https://dev.fdcyun.com/11logging/logging.html)
- 内置ClownFish的[身份认证](https://dev.fdcyun.com/4msvc/authenticate.html)和[授权检查](https://dev.fdcyun.com/4msvc/authorize.html)功能
- 提供经典的[HTTP管道开发模式](https://dev.fdcyun.com/10extension/http-pipeline.html)
